GRPO-Unhinged: The Hidden Advantage of Classification in RL Post-Training

RL for LLMs is classification-based policy iteration. With binary rewards, the clipped GRPO update is a weighted hinge loss on outcome-labeled tokens.

The view

Each token's log-ratio score acts as an estimate of its Q-value, the probability of success after that token. With a binary reward and no discounting, a token's advantage is how much that token raises the probability of success. The clipped GRPO update then classifies tokens against the outcome labels as a weighted hinge loss, with the score function as the decision boundary.

This places RLVR in classification-based policy iteration, and it shows that GRPO variants such as DAPO, GSPO and CISPO differ only in how they set four components: the class weights, the margins, the clipping and the score function.

Per-class loss normalization

Existing remedies for length growth change the normalization but treat correct and incorrect responses alike. A per-class loss normalization follows from the hinge loss perspective and normalizes the loss within each class. On maze navigation, with transformers trained from scratch to produce an A* search trace and a plan, it keeps incorrect responses at their original length, where GRPO doubles them, and reaches the highest accuracy.

Next directions

  • Multi-turn RL for LLM agents. Extending the classification view to credit assignment across turns, using turn-level advantages to decide which turns mattered while the tokens within each turn still receive the right signal.
  • Off-policy RL post-training. Deriving updates from the hinge loss perspective that remain valid when rollouts come from earlier policies, so stale or asynchronous rollouts can be reused instead of discarded.
